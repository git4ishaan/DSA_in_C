# DS Lab work

C implementations of Data Structures & Algorithms, written while learning.

## Programs

| File | Topic |
|------|-------|
| `ass1.c` | Matrix add / subtract / multiply / transpose |
| `saddle_point.c` | Saddle point of a matrix |
| `linear_search.c`, `binary_search.c`, `Searching_sorting.c` | Searching |
| `bubble_sort.c`, `selection_sort.c`, `Searching_sorting.c` | Sorting |
| `sparse_matrix.c`, `simple_trans.c`, `fast_trans.c`, `combi_sparse.c`, `sparse_add.c` | Sparse matrix |
| `stack.c`, `stack2.c` | Stack (infix→postfix, postfix evaluation) |
| `linear_queue.c`, `circular_queue.c` | Queues |
| `singlyll.c` | Singly linked list |
| `circlell.c`, `poly_add.c`, `poly_add_menu.c` | Circular list + polynomial addition |
